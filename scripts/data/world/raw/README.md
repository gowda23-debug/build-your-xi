# World Cup Raw Data

This directory contains source-backed raw data used to generate the
processed World Cup datasets.

## Authority

Primary sources:

1. ICC official tournament pages
2. ICC official match centres and scorecards
3. ICC official tournament statistics
4. ICC official tournament media guides/PDFs
5. ICC official player profiles
6. Official national cricket board sources where ICC does not provide
   the required historical information

Third-party sources may be used only for cross-checking.

## Important

Do not create empty files.

Do not create placeholder players.

Do not invent statistics.

Do not infer player roles solely from batting/bowling statistics.

Every player record must contain at least one authoritative source URL.

The processed files are generated from these raw files and should not
be manually edited.
