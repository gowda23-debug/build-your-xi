# Build Your XI — Phase 1

Current prototype includes:
- Landing page
- Login UI
- Registration UI
- Guest entry
- Home / challenge dashboard

## Run locally
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Important
Authentication and database are currently UI placeholders. Phase 1 backend integration should connect Supabase Auth and PostgreSQL before real progress persistence is added.
